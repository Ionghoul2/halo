# Car Glow install guide (draft, all tiers)

Time is 5–12 h by vehicle; see the matrix. Work in shade with the panels dry and above 10 °C / 50 °F.

1. **Wash and dry.** Wipe the tape contact points with isopropyl alcohol and a microfiber cloth (Sentra method).
2. **Plan with tape.** Mark the path with a few painter's-tape dots.
   - Keep doors, hood, trunk and charge port free (Festive Lights, BuiltRight).
   - Avoid headlights, taillights, license and third brake lights, windows and grilles (Toyota, Middleton).
3. **Protect the paint.** Lay removable vinyl strips where the wire will cross paint.
   - On PPF, use clear tape directly (Huracan).
   - Ceramic-coated or dark paint: test gaffer tape on one spot first (GT-R).
4. **Lay the strands.** Zig-zag from the rear of the car forward.
   - Tape every 30 cm (1 ft).
   - Double the tape on leading edges: hood nose, mirrors, roof front (BMW, Middleton).
5. **Cross openings with slack.** Leave a 5–8 cm slack loop at every door, hood and trunk gap, and route under the hinges.
   - A GT-R wire snapped at the trunk without slack.
6. **Bring the power in.** Run the leads through the door or trunk weather seal (use a trim tool) to a switched power strip inside the car.
7. **Power.** Use the power system listed for your kit (see `diagrams/power-wiring.svg`).
   - Socket inverter only up to about 120 W.
   - Run the engine for long displays.
   - EVs: 12 V socket only.
8. **Controller setup:**
   - **Classic:** pick a mode.
   - **RGB:** pair the app.
   - **Graphic Pro:** load our WLED map file for the vehicle, then upload a GIF.
   - **Elite:** Twinkly app, group as "Join", then camera-map (Huracan finding). If a strand drops off Wi-Fi, use a phone hotspot.
9. **Test.** Run it 15 minutes and check the inverter temperature. Hose-test if you will park outside.
10. **Remove.** Peel the tape slowly at 180° in warm weather. Coil the strands on reels. Clean any residue with an adhesive remover safe for automotive paint.

Not supported: driving with lights on, highway speeds, leaving the install outdoors for weeks.
